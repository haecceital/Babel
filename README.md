# Babel

存放所有我所學過的演算法、資料結構實現代碼和一些簡單講解+個人理解的repo
<br>
由於其中的內容可能涵蓋各種不同領域，所以用來實現的語言也會有所差異

例如，對於資料結構這類容易涉及指標操作操作、手動分配記憶體的類別，我使用的是C++
而演算法範式這種著重於行為邏輯則是用 Haskell

## 動機

因為每次我看到一些新的算法總是想去學，長此以往，有很多算法都是看到並產生好奇，但最終並沒有真的去學，所以我決定用這個repo記錄我學過的和未來想學的算法

另一個原因是有些算法我學完後可能實際使用次數不超過幾次，未來若是要再用到就是從頭開始學，與其每次都從頭開始，不如留點紀錄，加深我的印象
