# Babel

存放所有我所學過的演算法、資料結構實現代碼和一些簡單講解 + 個人理解的 repo <br>
由於其中的內容可能涵蓋各種不同領域，所以用來實現的語言也會有所差異

例如，對於資料結構這類容易涉及指標操作操作、手動分配記憶體的類別，我使用的是C++ <br>
而演算法範式這種著重於行為邏輯則是用 Haskell

## 動機

因為每次我看到新的算法時總是想學，但實際上我並不一定會真的去學，而是會一直拖延直到我忘記我要學這個算法，所以我決定用這個 repo 記錄我學過和想學的算法

另一個原因是有些算法我學完後實際使用次數只有個位數，未來若是要再用到只能從頭開始學，所以這個 repo 至少能給我學過的算法留點紀錄，在我重新熟悉時可以提供一些幫助
